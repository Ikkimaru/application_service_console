# Roadmap

## Milestone 1 — Architecture scaffold

Dynamic discovery, portable profiles, local settings, validation, port diagnostics, desktop shell, tests, and CI.

## Milestone 2 — Process lifecycle

Local command execution, tool preflight, dependency-aware start, reverse-order graceful stop, Windows process-tree cleanup, health checks, crash recovery, and temporary port override confirmation.

## Milestone 3 — Log workspace

Asynchronous stdout/stderr ingestion, structured parsing, SQLite FTS5 indexing, batched writes, filters, bookmarks, export, redaction, and configurable retention.

## Milestone 4 — Distribution and extensibility

Signed installer, update policy, profile import/export, Docker/WSL/Windows-service providers, accessibility audit, and release hardening.
